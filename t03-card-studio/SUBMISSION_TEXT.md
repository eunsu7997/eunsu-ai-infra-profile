## 재현·통과 확인 4가지

**어디로 가나요:**  
https://eunsu7997.github.io/eunsu-ai-infra-profile/t03-card-studio/

**무엇을 하나요(3단계 이내):**  
1) PNG 또는 JPEG 이미지를 불러오거나 기본 그라데이션 배경을 사용합니다.  
2) 문구의 위치·크기·색을 바꾸고 1:1 / 4:5 / 9:16 중 하나를 선택합니다.  
3) PNG 다운로드를 눌러 저장 결과가 미리보기와 같은지 확인합니다. 필요하면 템플릿 저장/불러오기와 JSON 백업·복원도 확인합니다.

**무엇이 보이면 통과:**  
문구 변경이 즉시 미리보기에 반영되고, 1:1·4:5·9:16에서 다운로드 PNG의 이미지 잘림·문구 위치·줄바꿈이 미리보기와 일치합니다. 지원하지 않는 파일이나 손상/필수 항목 누락 JSON은 이유를 표시하며 기존 작업을 유지합니다. 저장한 템플릿은 불러오기·수정·삭제할 수 있고 새로고침 뒤에도 유지됩니다.

**안 될 때:**  
잘못된 파일이나 JSON 때문에 기존 편집 내용이 사라지거나, 미리보기와 다운로드 결과가 다르거나, 템플릿 생성/불러오기/수정/삭제가 동작하지 않거나, 새로고침 뒤 저장 템플릿이 사라지거나, Console에 빨간 오류가 발생하면 실패입니다.

## AI와 내 판단 3줄

**AI에게 맡긴 일:**  
과제 조건을 C03~C32 기능 요구사항으로 정리하고 편집기 코드, PNG/JPEG 검증, Canvas 미리보기·저장, 템플릿 CRUD, JSON 검증·복원, 극단 입력 및 회귀 QA 문서를 구현·점검했습니다.

**내가 직접 판단한 일:**  
복잡한 다중 레이어 편집기보다 검증 가능한 PIXEL CARD STUDIO 방향을 선택하고, 이미지 1장 + 문구 1개 + 1:1·4:5·9:16 비율을 핵심 범위로 정했습니다. 잘못된 입력이 와도 기존 작업을 유지하고, 미리보기와 다운로드 결과가 반드시 같아야 한다는 기준을 우선했습니다.

**AI 제안을 따르지 않은 일(없으면 그 이유):**  
별도로 폐기한 핵심 제안은 없습니다. 처음부터 과제 조건 누락을 막기 위해 기능 범위를 작게 고정하는 방향에 AI 제안과 제 판단이 일치했고, 이후에도 검증에 필요하지 않은 기능은 추가하지 않기로 했습니다.
