## 실제 결함 수정 로그

### 결함 1 — 첫 화면에서 활동·근거가 보이지 않음
- 수정 전: hero가 사실상 자기소개만 차지해 1366×768 첫 화면에서는 강점/근거가 아래로 밀릴 가능성이 컸음.
- 수정 후: 첫 화면을 2열 구조로 바꾸고 오른쪽에 `ACTIVITY`와 `EVIDENCE` 카드를 고정 배치해 소개·활동·근거를 동시에 노출.
- 확인: 1366×768, 1920×1080 viewport에서 세 요소 존재 여부를 검사.

### 결함 2 — reduced motion CSS 문법 오류
- 수정 전: `.reduce-motion *,@media (prefers-reduced-motion:reduce)`처럼 selector와 `@media`가 한 규칙에 섞여 CSS 파싱이 불안정했음.
- 수정 후: `.reduce-motion *` 규칙과 `@media (prefers-reduced-motion: reduce)` 블록을 분리.
- 확인: 움직임 줄이기 버튼을 눌렀을 때 body에 `reduce-motion` 클래스가 생기고 애니메이션이 비활성화됨.

### 결함 3 — 소개 항목과 공개 가능한 근거의 직접 연결 부족
- 수정 전: 강점 설명은 있었지만 한 소개 항목에서 바로 공개 근거를 열 수 있는 링크가 없었음.
- 수정 후: 첫 화면 공개 근거 카드와 3번째 강점 상세에 공개 GitHub 저장소 링크를 연결.
- 확인: 링크를 새 세션에서 열어 저장소가 공개로 보이는지 확인.

### 결함 4 — 작은 화면에서 주요 메뉴가 사라짐
- 수정 전: 900px 이하에서 주요 `nav`가 `display:none`이 되어 키보드/터치 사용자가 메뉴를 사용할 수 없었음.
- 수정 후: 메뉴를 숨기지 않고 다음 줄로 감싸도록 변경.
- 확인: 좁은 화면에서도 메뉴 링크가 DOM과 화면에 남고 Tab 이동 가능.

### 결함 5 — 모바일에서 긴 텍스트가 grid 최소폭을 밀어 가로 스크롤 발생
- 수정 전: 390px 검사에서 `scrollWidth`가 414px로 늘어나 가로 스크롤이 생김.
- 수정 후: grid 자식에 `min-width:0`을 주고 긴 텍스트에 `overflow-wrap:anywhere`를 적용.
- 확인: 390px viewport에서 `scrollWidth === innerWidth`로 재검사.

## 재현·통과 확인 4가지
- 어디로 가나요: `https://eunsu7997.github.io/eunsu-ai-infra-profile/`
- 무엇을 하나요(3단계 이내): ① `강점과 근거`로 이동 ② 첫 강점 카드를 클릭 ③ Tab으로 다음 카드에 이동해 Enter 또는 Space를 누름
- 무엇이 보이면 통과인가요: 첫 화면에 소개·현재 활동·공개 근거가 함께 보이고, 강점 카드가 마우스와 키보드에서 모두 펼쳐지며 상황·행동·결과가 나타남
- 안 될 때 무엇이 보이나요: 링크가 열리지 않거나 카드가 펼쳐지지 않거나 가로 스크롤/콘솔 오류가 보이면 미통과로 보고 배포 파일과 브라우저 콘솔을 다시 확인

## AI와 내 판단 3줄
- AI에게 맡긴 일: 과제 조건을 기준으로 페이지 구조·반응형 CSS·접근성·상호작용 코드 초안을 만들고 조건 누락을 점검하게 했습니다.
- 내가 판단한 일: 어떤 경험을 공개할지, 어떤 강점을 보여줄지, 공개 범위와 최종 문구가 실제 나와 맞는지를 직접 판단했습니다.
- AI 제안을 따르지 않은 일: 과제와 관계없는 개인정보나 과장된 경력은 넣지 않았고, 실제로 공개 가능한 경험과 확인 가능한 근거만 남겼습니다.
