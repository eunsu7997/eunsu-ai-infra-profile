# RAID//ZERO — ALEPH T02

브라우저에서 실행되는 28초 보스 패턴 회피 미니게임입니다.

- 결과 주소: https://eunsu7997.github.io/eunsu-ai-infra-profile/t02-mini-game/
- 소스 주소: https://github.com/eunsu7997/eunsu-ai-infra-profile/tree/main/t02-mini-game
- 핵심 조작: WASD/방향키 이동, Space 대시, P 일시정지, R 결과 화면에서 재시작
- 성공: 28초 생존
- 실패: HP 0

## T02 제출용 짧은 확인법

- 어디로 가나요: 결과 주소로 이동합니다.
- 무엇을 하나요(3단계 이내): ① 훈련 시작 ② WASD/방향키로 장판을 피하고 Space로 대시 ③ 성공/실패 화면에서 R 또는 다시 시작을 누릅니다.
- 무엇이 보이면 통과인가요: 규칙·조작·현재 상태가 계속 보이고, 28초 이내 성공 또는 실패 뒤 재시작하면 HP/시간/점수/위치/패턴이 초기화됩니다.
- 안 될 때 무엇이 보이나요: 입력 1회가 여러 번 처리되거나, 재시작 후 이전 판 상태가 남거나, 일시정지 중 시간이 흐르거나, 화면 가로 넘침/콘솔 오류가 보이면 실패입니다.

## AI와 내 판단

- AI에게 맡긴 일: 과제 조건표를 기능 요구사항으로 바꾸고, 게임 코드·반응형 화면·저장값 복구·효과 줄이기·검사용 디버그 훅 초안을 구현하고 누락 조건을 점검했습니다.
- 내가 직접 판단한 일: 전날 만든 RAID//ZERO의 장판 회피 콘셉트를 유지하고, 28초 한 판·HP 5·3단계 패턴·대시 중심 조작을 최종 게임 방향으로 선택했고, 난이도 비교 기록을 보고 패턴 간격 0.74초를 최종값으로 정했습니다.
- AI 제안을 따르지 않은 일: 단순 CPU 게이지를 버튼으로 낮추는 Server Shield 방식은 게임성이 부족하다고 판단해 사용하지 않고, 직접 움직이며 피하는 레이드 회피 게임으로 바꿨습니다.

세부 조건 대응과 난이도 비교 기록은 `T02_EVIDENCE.md`를 확인하세요.
